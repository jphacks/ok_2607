## 製品概要

### 背景(製品開発のきっかけ、課題等）

メモやタスク管理アプリにやりたいことを書き出しても、書いたこと自体を忘れたり、タスクが積み上がって古いものが埋もれたりします。やりたいこと（趣味・勉強・挑戦）は増え続ける一方で、使える時間や体力には限りがあり、何を諦めるかを決められないまま優先順位が曖昧になり、目の前の行動を選べなくなります。進まないタスクが積み上がると、焦りや罪悪感でさらに決められなくなります。

そこで私たちは「どうすれば、やりたいことを多く抱える人が、実現できない希望を納得して手放し、本当に大切なことに集中できるだろうか？」という問いから開発を始めました。

### 製品説明（具体的な製品の説明）

やりたいこと・やるべきことを大量に抱える人は、本当に大切なことに集中したいのに、タスクが積み上がって何から手を付けるか決められずに困っています。ToDo アプリや AI チャットで管理しても、この問題は解決しません。このアプリは、**3択から 1 つ選ぶだけで「やらないこと」も自然に決まり、AI が完了までの道筋を示してくれる**タスク管理 Web アプリです。

1. 優先順位や詳細を決めずに、タスクを書き出す
2. ローグライクゲームの報酬選択のように、提示された 3 つのタスクから 1 つだけ選ぶ
3. 選んだタスクを AI がチェックポイントに分解し、次の一歩を示す
4. チェックポイントを 1 つずつクリアしてタスクを完了し、経験値を得る

### 特長

#### 1. 3択で「やること」「やらないこと」を決める

一度に見せるのは 3 つだけ。選ばなかったタスクは出にくくなり、自然に断捨離が進みます。締切が近いタスクは「緊急クエスト」として 1 択で登場し、やるべきことからは逃がしません。

#### 2. 選択から学ぶレコメンド

提示されたのに選ばれなかったタスクはreject回数が増え、`1 / (reject回数 + 1)` を正規化した確率で出現しにくくなります。何を選び、何を選ばなかったかの記録から、本人が本当に大切にしていることを浮かび上がらせます。

#### 3. AI チェックポイントで道筋から外れない

AI とのチャットで立てた計画は会話に埋もれがちです。このアプリでは、タスクを「全体像のチェックポイント → 細かい行動」に分解して保存し、1 つずつ順番にクリアしていけます。

### 解決出来ること

- やることが多すぎて何から手を付ければいいかわからない状態をなくす
- 実現できない「いつかやりたい」を納得して手放せる
- タスクを分解する手間なく、次にやることが決まっている

### 今後の展望

- Google カレンダーとの連携と、AI によるタスクの所要時間の予測
- 長期目標を設定し、目標に合うタスクを出やすくする
- 紙に書いたメモを写真から取り込む（端末上の AI による画像認識）
- ログイン機能と複数デバイス対応

### 注力したこと（こだわり等）

- 自己決定理論をもとに「自分で選んだ」と感じられる 3択の体験
- 選択の記録に基づくレコメンドアルゴリズム
- AI の出力を構造化して保存し、計画がずれないようにしたチェックポイント生成

- Web ブラウザ（PC・スマートフォン）

### 独自技術

#### ハッカソンで開発した独自機能・技術、特に力を入れた部分

#### 1. 3択によるタスク推薦・選択システム

タスクを3つに絞って提示し、直感的に1つを選べるUIを開発しました。選ばれなかった回数（reject回数）に基づいて抽選確率を調整する独自ロジックを実装しています。また、カードの選択演出や即決ボーナスなどによって、迷わずタスクを決められる体験を追求しました。

- PR #40：reject回数に基づく抽選

- PR #114：3択カードのゲーム演出

#### 2. 生成AIによるチェックポイント自動生成

Gemini APIを活用し、抽象的なタスクを実行しやすい具体的なステップへ自動分解する機能を開発しました。生成結果をスキーマで検証し、AIの応答が失敗した際も代替チェックポイントを提供できるようにしています。生成後のステップ編集・並び替えにも対応しました。

- PR #19：AI障害時のフォールバック

- PR #107：チェックポイントの追加・編集・並び替え

#### 3. タスクの実行を促すゲーム体験

チェックポイントを順番に達成する仕組みや、現在取り組むべきステップを強調するUIを実装しました。クエスト完了時には経験値を獲得し、レベルアップや紙吹雪などの演出によって達成感を得られる設計にしています。

- PR #78：順番に進めるチェックポイントUI

- PR #66：経験値とレベルアップ

- PR #79：クエストクリア演出
