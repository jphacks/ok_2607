# ゲームフィール見直し 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 配色をネオン寄りに変え、3択カードにレア度を付け、主要操作すべてに演出・音・振動の反応を付ける。

**Architecture:** 色とアニメーションは `tokens.css` の `@theme` にトークンとして定義し、Tailwind のクラス（`bg-surface`、`animate-shake` など）で使う。演出の共通部品（飛び出す文字・効果音・振動・動きの低減判定）は `src/components/ui/` に置き、各画面はそれを使うだけにする。判定ロジック（レア度・コンボ）は各機能フォルダの純粋関数にする。

**Tech Stack:** Next.js 15 / React 19 / Tailwind CSS v4 / Vitest + Testing Library。新しい依存パッケージは追加しない。

**Spec:** `docs/superpowers/specs/2026-10-18-game-feel-design.md`

## Global Constraints

- 新しい依存パッケージを追加しない（アニメーションは CSS `@keyframes`、音は Web Audio API）
- 画面のコードに 16 進数の色を書かない。触ったファイルの既存の 16 進数はトークンに置き換える
- 1 つの演出は 0.5 秒以内。クリア画面だけ 1.5 秒まで、タップでスキップできる
- `prefers-reduced-motion: reduce` では移動・揺れ・拡大・フラッシュを止める（既存の `globals.css` の全体ルールで止まる。JS で動かすものは `usePrefersReducedMotion()` で止める）
- `localStorage` の読み書きは try/catch で囲み、失敗したら音なしとして動く
- 文言は日本語。ゲーム用の英字（`QUEST CLEAR!`、`LEVEL UP!`、`COMBO ×2`）はそのまま
- 1 PR は 15 ファイル以内。共通ファイル（`tokens.css`、`globals.css`、`src/components/ui/`、`docs/design.md`）の PR を先にマージしてから画面の PR を出す
- 各 PR は Issue（`.github/ISSUE_TEMPLATE/task.md`、`task` ラベル、Assignee は依頼者）に紐づけ、`/ship` の流れでマージする。最後の PR だけ `Closes #番号`、それ以外は `Refs #番号`

## Review Focus

1. 効果音を連打したとき（チェックを素早く何度も切り替える）に AudioContext が増え続けない → `sound.test.ts` で `playSfx` を 3 回呼んでも AudioContext の生成は 1 回
2. チェックを外してから付け直したとき、XP の飛び出しとコンボが二重に加算されない → 完了に変わったときだけ演出を出す（`QuestProgressScreen.test.tsx`）
3. `localStorage` が使えない環境（プライベートモード）で画面が壊れない → `sound.test.ts` で `getItem` が throw しても `isSoundEnabled()` が `false` を返す
4. 動きの低減を指定した利用者に、クリア画面の XP カウントアップが動かずに最終値がすぐ出る → `use-count-up.test.ts`
5. 緊急クエストが reject 回数の多いタスクでも、緊急の見た目が優先される → `rarity.test.ts`

| `clear`   | 523 → 659 → 784Hz 各 0.06 秒            |
