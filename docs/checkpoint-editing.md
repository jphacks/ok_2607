# チェックポイント名の編集

Issue #83。生成画面ではカードを選択して名前を編集し、Enterまたはフォーカスを外す操作で保存する。Escapeは編集を取り消し、保存しない。IME変換確定のEnterでは保存しない。

名前は前後空白を除いて1〜200文字。保存中は重複保存とクエスト開始を抑止する。保存成功を確認してから画面に反映し、失敗・不正な応答では編集入力を保持して再試行を表示する。編集中はクエスト開始を無効にする。

APIは先行PR #89のUpdateCheckpointFieldsRequestを使う。titleとisDoneは部分更新で、指定した項目だけを保存する。名前だけの変更では達成状態と完了日時を保持する。Cookie認証とクエスト・元タスクの所有者検証を経由し、他ユーザーのチェックポイントは更新しない。

公開デモはAPIを呼ばずローカル表示だけを更新する。
