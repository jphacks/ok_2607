# チェックポイントコンポーネントのデザイントークン統一

Issue #109。`AGENTS.md` および `docs/design.md` のルール（「色は `src/app/tokens.css` のトークンを使い、16進数を直接書かない」）に基づき、チェックポイント機能配下の各コンポーネントに残っていたハードコードされた 16 進数カラー指定を Tailwind デザイントークンに統一した。

## 適用したデザイントークン一覧
